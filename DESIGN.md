# AARO Design System

## Direction

AARO is a Bangladesh-focused, multi-category lifestyle shop. The experience should feel calm, current, and considered, with enough warmth to feel approachable. Use a clear product-first layout, generous breathing room, crisp photography, and direct language. Adapt the supplied Peak Design reference; do not reproduce its site or identity.

## Tokens

- Ink: `#1E293B`
- Primary blue: `#2563EB`
- Teal: `#0F766E`
- Pale teal: `#E0F2F1`
- Amber accent: `#F59E0B`
- Muted text: `#64748B`
- Page background: `#F7F8F5`
- White: `#FFFFFF`
- Borders: `#E2E8F0`
- Maximum content width: `1440px`
- Spacing base: `4px`, favoring 8 / 16 / 24 / 32 / 48 / 64px
- Controls: 8–14px radius; image cards: 16–22px radius; pills: full radius

## Type

Use Manrope for display and headings, DM Sans for body and controls. Headings are confident and compact; body copy stays readable and conversational. Price and checkout information should remain visually clear.

## Components

- Sticky utility/brand header with a prominent search field
- Product cards with large 4:5 imagery, category, title, price, and save/quick-add actions
- Warm editorial hero with a clear shopping call to action
- Reusable category chips, offer cards, and collection sections
- Responsive cart drawer and guest checkout
- Restrained shadows, visible focus rings, and accessible contrast
- Admin interface uses the same palette with compact data tables and strong status colors

## Behavior

Design for mobile first. Search, add to bag, save to wishlist, checkout, coupon entry, and admin order confirmation must be easy to find. Keep the storefront fast by using responsive image URLs and avoid loading the complete product catalog into a single visual section.
